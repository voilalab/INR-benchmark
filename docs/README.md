# Project page

Static GitHub Pages site for “Grids Often Outperform Implicit Neural Representations at Compressing Dense Signals.” The visual system follows the VOILA Lab @ GT website and uses figures and quantitative results from the authors’ paper.

The page includes the benchmark coverage map, 27 synthetic source signals, the eight-model roster, and a task-and-budget quantitative explorer. Its visual results are split into three dedicated sections: 19 appendix qualitative plates, six full bandwidth heatmaps, and separate performance-curve figures for fitting and inverse problems.
