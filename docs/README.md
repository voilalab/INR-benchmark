# Project page

Static GitHub Pages site for “Grids Often Outperform Implicit Neural Representations at Compressing Dense Signals.” The visual system follows the VOILA Lab @ GT website and uses figures and quantitative results from the authors’ paper.

The page includes the benchmark coverage map, 27 synthetic source signals, the eight-model roster, a task-and-budget quantitative explorer, qualitative result figures, practical guidance, and citation metadata.
